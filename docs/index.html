Tính năng

🎬

Lồng tiếng AI

Tự động dịch + lồng tiếng video với Whisper + TTS chất lượng studio. Batch xử lý nhiều video.

🎙️

Clone giọng

Tạo giọng nói AI từ 5–30 giây audio mẫu. Dùng lại trong TTS và lồng tiếng.

📝

Speech to Text

Trích xuất phụ đề từ audio/video ra SRT, VTT, TXT, JSON, CSV. Hỗ trợ 90+ ngôn ngữ.

🌍

Dịch thuật

Dịch đa ngôn ngữ qua Google Translate, GPT, Claude, DeepL, Gemini. Dùng API key cá nhân.

⬇️

Tải video

Tải video từ TikTok, Douyin, YouTube, Facebook, Instagram, Bilibili… với nhiều độ phân giải.

🔒

Riêng tư

Dữ liệu lưu trên máy bạn. API keys mã hoá qua OS Keychain. Không tracking, không quảng cáo.
